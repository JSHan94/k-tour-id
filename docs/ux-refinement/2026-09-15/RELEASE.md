## 사용자에게 달라진 흐름

| 흐름 | 변경 |
|---|---|
| 지도 → 장소 → 혜택 | 등록된 목업 매장 미리보기는 혜택과 상세 두 액션. 작은 화면에서도 두 버튼을 유지하고, 서비스에서 돌아오면 같은 장소의 읽던 위치와 펼친 설명을 복원한다. 미지원 장소에 결제·예약 지원을 만들어내지 않는다. |
| 지갑 → 충전 / 주문 → 부족분 충전 | 지갑에서 충전하면 잔액으로, 주문에서 충전하면 같은 주문 검토로 복귀한다. 충전 수단에 기존 잔액을 다시 제시하지 않는다. 완료된 이전 영수증이 새 수단 선택을 가리지 않으며, 미확정 작업은 동일 건으로 조회한다. |
| 구매 → 환불 → 내역 | 중복 전액 환불 버튼을 없애고 부분·잔여 전액·실패·미확정 조회를 공통 패널 하나로 제공한다. My Korea는 선택한 구매의 실제 목업 주문/결제/확정 환불 참조와 정확한 장소를 보여준다. 다른 구매의 환불은 섞지 않는다. |
| 장소 콘텐츠 | 학림다방 1곳 추가로 조사 추천 25곳. 어니언 안국과 학림에 출처·라이선스·번역 대체 텍스트를 갖춘 로컬 실제 사진 2장을 적용했다. 사진 오류도 같은 크기의 안내로 처리한다. 서비스 등록은 기존 27곳 그대로다. |
| 첫 진입·온도 | 지도 우선 진입을 유지한다. 선택형 취향 설정을 강제하지 않는다. 기존 지도/장소의 공통 샘플 시간 프레임을 유지하고 작은 활동 표시의 가독성을 높였다. 실제 방문·실시간 인기도로 꾸미지 않는다. |

## 개발자에게

- [Deployment Spec](../../DEPLOYMENT_SPEC.md)의 G03/G09-S/G10에 이 화면 계약을 반영했다. `purpose`, 원 매장, 동일 operation, 주문별 환불 참조, 복귀 snapshot은 UI 문맥이며 서버의 승인·지급 권한이 아니다.
- [짧은 해커톤 인계서](../../HARVEY_HACKATHON_HANDOFF_2026-09-14.md)의 CX·OpenDID·Sui·OmniOne 실연동 범위는 바꾸지 않았다. 순수 목업과 별도 Sumsub 실험을 합치지 않았다.
- [코드 지도](./sitemap-code.md)와 [브라우저 지도](./sitemap-browser.md), [변경 합의](./decisions.md)에 유지·통합·보류와 실행 증거를 구분했다. 78개 의미 노드/264개 전이 행은 목록 크기이지 전체 실제 실행 PASS 수가 아니다.

위 결과를 서로 합산해 전체 상태 조합 완료라고 표시하지 않는다. 각 viewport는 Chromium 에뮬레이션이며 실제 휴대전화 검수가 아니다. 앱 코드는 `505e475`에서 고정했고 후속 결과 문서와 배포 환경 구분 테스트만 main/Harvey에 동일 반영한다.

중간 검수에서 작은 화면의 CTA 가림, 사진 비율, My Korea의 고정 영수증/매장명, 기존 구매가 있는 동안의 빈 내역 안내를 발견해 수정했다. 다수 브라우저 동시 실행 중 timeout이 발생한 실행은 실패/중단 기록으로 남겼다. 정확한 원인을 부하로 단정하지 않았고, 단독 재현에서는 발생하지 않았으며 최종 최대2worker 검사에서 통과했다. [시각 검수](./adversarial-visual-wave1.md), [거래 검수](./adversarial-root-wave2.md).

## 남은 범위

- **UX-08 목업 완료·실연동 남음:** 사용자 승인으로 추가한 비금전 체험은 `5712aed`에서 지정 검수·운영 배포했다. [체험 목업 인계](../../EXPERIENCE_MOCK_HANDOFF_2026-09-15.md)에 연결·실패 계약, [새 릴리스](../../KTOUR_EXPERIENCE_RELEASE_2026-09-15.md)에 실제 검사 범위를 기록한다. 기존 금융/Labs 결과를 새 체험의 증거로 쓰지 않으며 실제 네 기술 호출은 개발 대상이다.
- 나머지 사진/신규 장소 후보는 권리·위치·실제 장소 일치가 승인되지 않아 보류했다. 모든 빈 사진 칸을 채웠다는 뜻이 아니다.
- 실제 CX/OpenDID/Sui/OmniOne, 실제 자금·예약, 실시간 군중 데이터, 물리 iPhone/Android의 앱 호출·카메라 검수는 이번 결과가 아니다. 전체 상태 조합이나 미적 완벽함을 보증하지 않는다.
