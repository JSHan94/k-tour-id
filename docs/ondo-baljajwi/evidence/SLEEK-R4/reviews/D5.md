## 4. Fresh traveler journey inspection

### First use, discovery, and return

- `390×844`에서 Value → `Visiting Korea` → interest/dietary preferences → guest map을 실제 클릭했다. KYC가 onboarding을 선점하지 않았고, dietary preference가 보장으로 오해되지 않는 고지를 확인했다.
- Seoul과 Busan을 오가며 `pizza` search, list, map, place peek/detail, empty/clear recovery를 확인했다. 공식 한글 상호명과 navigation용 표기, unknown fact, source/truth가 구분됐다.
- place directions가 선택한 venue 좌표를 보존하는지, reload 후 persona/preferences/saved venue가 My Korea에서 유지되고 같은 venue로 돌아가는지 확인했다.

### JIT identity and local contribution

- guest Save에서 account gate cancel → exact venue return, account failure → retry → completion → exact venue save를 확인했다.
- Resident persona에서 Residence unsupported → passport alternate → simulated completion → 보존된 Local Signal draft 복귀를 확인했다.
- Korean local persona는 onboarding 직후 CX를 강제하지 않고 Local Signal action에서만 OmniOne CX를 열었다. 실패·retry 후 원래 note draft가 유지됐다.
- Local Signal은 빈 제출 disabled, note/photo 중 하나 요구, failure 후 draft 보존, retry success, local-only truth를 제공했다.

### After19, Tables, and communication safety

- 일반 장소 사실은 잠금 뒤에도 읽혔고 After19 content만 Age proof를 요구했다. cancel, failure, retry, success 후 같은 venue와 `After19 ON`으로 복귀했다.
- venue-scoped Table이 없을 때 exact venue return과 global Tables 탐색 두 recovery가 모두 보였다.
- Table join failure/retry, confirmed-member chat, text/image state, report+block, check-in, 두 축 feedback, leave cancel, reload persistence를 확인했다. nationality/gender 강제 matching 또는 통합 safety score는 나타나지 않았다.

### Payment, stamp, My Korea, Trust, and Labs

- 독립 Payment KYC cancel/failure/retry, checkout cancel, decline, simulated receipt를 확인했다. cancel/decline은 balance·receipt·stamp를 바꾸지 않았다.
- 결제와 별도인 preview visit이 `9→10` stamp를 만들었고, My Korea가 saved venue와 milestone을 보존했다.
- ID/Profile에서 Account/Person/Age/Payment 상태 분리, 선택적 public field, provenance, 네 reputation 축 분리를 확인했다.
- Labs acknowledgment, signer preview, read-only assets, trait stale/retry, bridge cancel/failure/success 순서, badge opt-in을 확인했다. bridge receipt와 badge preview는 자산 또는 NFT 발행을 가장하지 않았다.
