# ONDO 발자취형 비지도 시각 시스템

## 목적

ONDO의 기능과 상태 계약은 유지하면서, 발자취 앱에서 확인되는 **큰 여백, 중립 캔버스, 얇은 구분선, 한 번에 하나의 주 행동**을 비지도 화면에 적용한다. 발자취의 화면이나 자산을 복제하지 않고 정보 밀도와 시각 위계 원리를 추상화한다.

참고 기준:

- Apple App Store `발자취 - 전국지도, 타임라인, 여행일지`: <https://apps.apple.com/kr/app/id6792431474>
- `docs/ONDO_UX_DESIGN_SPEC.md`
- `docs/ondo-execution/06_CONTENT_LOCALIZATION.md`
- `docs/ondo-execution/07_VISUAL_INTERACTION_SPEC.md`

## 핵심 원칙

1. 캔버스는 `#fbfaf7`, 표면은 흰색 또는 투명으로 유지한다.
2. 콘텐츠 그룹은 둥근 카드와 그림자 대신 `1px` hairline과 28–38px의 수직 여백으로 구분한다.
3. 타이틀은 시스템 산세리프와 굵기/크기만으로 위계를 만든다. 장식용 명조 사용은 제거한다.
4. 열기 색은 지도 위 ONDO 신호에만 사용한다. 계정, DID, 스탬프, Labs, 신뢰도에 열기 팔레트를 빌려 쓰지 않는다.
5. 성공·실패·After19는 각각 초록·적색·짙은 자두색을 의미색으로만 제한한다.
6. 한 화면에서 채워진 버튼은 핵심 행동 하나만 둔다. 취소, 건너뛰기, 보조 경로는 투명 또는 hairline 버튼이다.
7. 터치 타깃은 최소 `44px`, 본문/메타데이터는 최소 `12px`를 지킨다.
8. 기능·상태·`returnTo`·미리보기 진실 고지 문구는 시각 개편으로 삭제하거나 축약하지 않는다.

## 토큰

| 역할 | 값 | 사용 |
|---|---|---|
| Canvas | `#fbfaf7` | 온보딩, ID, Tables, My, Labs 기본면 |
| Surface | `#ffffff` | 입력, 메시지, 제한적 모달 |
| Ink | `#20201e` | 제목, 핵심 버튼 |
| Muted | `#77746e` | 설명, 메타데이터 |
| Hairline | `#dedbd5` | 섹션/행 경계 |
| Subtle | `#f1f0ec` | 선택된 행, 메시지 영역 |
| Success | `#2f624a` | 검증/결제 성공 |
| Danger | `#8b302b` | 실패/삭제 |
| After19 | `#30232a` | 성인 모드의 명시적 상태와 1차 행동 |

## 컴포넌트 규칙

### 섹션과 행

- 바깥 카드 대신 섹션 상단 hairline과 22px 이상의 상단 여백을 사용한다.
- 리스트는 하나의 상단선과 각 행 하단선으로 연결한다.
- 행 내부 아이콘은 36–48px 원형 outline을 기본으로 하고 색 채움은 상태 성공/실패에만 허용한다.

### 버튼

- Primary: Ink 또는 After19, 높이 50–52px, radius 12–13px.
- Secondary: 투명 배경, hairline 또는 무테, 높이 44px 이상.
- 위험 행동: 붉은 채움보다 붉은 hairline/텍스트를 우선한다.

### 시트와 오버레이

- 공통 Sheet의 초점/키보드/닫기 동작을 유지한다.
- 내부 콘텐츠는 또 다른 카드로 감싸지 않는다.
- 진실 고지는 badge 묶음이 아니라 12px 설명문 또는 hairline 구간으로 노출한다.

### 반응형

- 390px/430px: 좌우 18–24px, 단일 열, 긴 KO/EN 문구 줄바꿈 허용.
- 700px 이상: 전체화면 문서형 표면은 최대 700px, JIT 시트/온보딩은 최대 430px로 읽기 폭을 제한한다.
- 360px 이하: 2열 상세와 증거 목록을 1열로 전환한다.

## 변경 전후 판단

| 문제 | 이전 | 개편 |
|---|---|---|
| 배경 | 누런 종이색/방사형 장식 | nearly-white 중립 캔버스 |
| 정보 그룹 | 둥근 카드가 카드 안에 반복 | 여백 + hairline 섹션 |
| 강조 | 적갈·주황이 전 화면 장식 | 지도 열기에만 열기 색 예약 |
| 버튼 | 채워진 CTA와 pill 다수 | 1 primary + 평면 secondary |
| 그림자 | 카드/칩/배너마다 사용 | 비지도 표면에서 제거 |
| 글꼴 | 장식용 display 혼용 | 읽기 쉬운 시스템 산세리프 |
| 기술 화면 | 기능마다 별도 색/카드 | 중립 문서형 레이아웃, truth copy 유지 |

## 금지 사항

- 발자취 로고, 화면, 지도 자산을 복사하지 않는다.
- 인증되지 않은 사용자에게 verified 시각 상태를 만들지 않는다.
- 미리보기 기능을 실제 외부 연동처럼 보이게 하는 배지/카피를 추가하지 않는다.
- 지도 열기 팔레트를 신뢰도, 스탬프 진행, Labs 장식에 사용하지 않는다.
- 공간을 줄이기 위해 메타데이터를 12px 미만으로 축소하지 않는다.
