# K-Tour ID 대한민국 여행지도 요구사항

Status: Map-first B variant implementation contract  
Branch: `experiment/map-first-daedongyeojido`

## 1. Product objective

K-Tour ID의 첫 화면을 대한민국 여행에 특화된 실제 지도이자 여행 실행 화면으로 만든다. 사용자는 전국의 여행 맥락을 한눈에 이해하고, 지역과 장소로 자연스럽게 확대해 액티비티를 발견하며, 선택한 장소에서 이동·식사·예약·혜택을 이어갈 수 있어야 한다.

대동여지도는 골동품 장식이 아니라 다음 정보 설계 원칙으로 번역한다.

- 영토를 한눈에 읽는 명확한 윤곽
- 산줄기·물길·길의 연결 관계
- 전국을 지역 단위로 이해하는 지도 판
- 적은 수의 일관된 기호와 범례
- 한지, 먹, 인장, 청회색 물길의 절제된 조형 언어

현대 지도 좌표와 도로가 언제나 사실의 기준이며, 전통적 산수 표현은 해석 레이어다.

## 2. Geographic scope

- 서비스 기본 범위는 대한민국 본토와 제주 및 부속 도서다.
- 첫 진입은 대한민국 전체를 읽을 수 있는 전국 뷰다.
- 중국·일본·북한의 도로와 POI는 초기 전국 뷰에서 노출하지 않는다.
- 지도 바깥은 한지색 마스크로 덮고 이동 범위를 대한민국 인접 영역으로 제한한다.
- 위치 허용 또는 명시적인 장소 선택 뒤에만 지역·장소 뷰로 이동한다.
- 국가 윤곽은 검증된 지리 데이터에서 가져오며 장식용 실루엣으로 대체하지 않는다.

## 3. Three map states

### Nationwide — 전국

- 대한민국 윤곽, 제주, 주요 여행 권역, 대표 산줄기·물길만 보인다.
- 액티비티는 개별 핀 대신 지역별 수량 또는 대표 기호로 집약한다.
- 사용자는 서울·부산·제주·경주·전주·강릉 등 여행 권역을 바로 선택할 수 있다.
- 대동여지도 조형 언어가 가장 강하게 드러나는 단계다.

### Regional — 지역

- 선택 지역의 주요 도시·동네, 이동 축, 장소·액티비티 묶음을 보여준다.
- 전국으로 돌아가는 명시적 컨트롤을 제공한다.
- 지역 이름, 결과 수, 현재 적용 필터를 항상 확인할 수 있다.

### Place — 장소

- 실제 도로와 위치 정확성을 우선한다.
- 개별 장소·액티비티와 접근 가능한 선택 상태를 제공한다.
- 대동여지도 질감은 낮아지고 지도 라벨과 경로의 가독성이 높아진다.
- 장소 선택 후에 이동·전후 식사·예약·혜택 가지가 나타난다.

## 4. Visual system

| Role | Treatment |
| --- | --- |
| Sea / outside mask | 옅은 청회색 또는 한지 회색, 낮은 대비 |
| Korea land | 따뜻한 한지 아이보리 |
| Coast / border | 먹색 이중선 또는 번짐 없는 굵은 윤곽 |
| Mountain network | 회갈색 능선선, 전국 뷰에서만 강조 |
| Water network | 절제된 청회색 선 |
| Primary route | 먹색 또는 인장 적색, 실제 경로와 장식선 구분 |
| Activity marker | 인장 적색, 기호와 텍스트로도 종류 표현 |
| Mobility marker | 단청 남색 |
| Food marker | 황토색 |
| Together marker | 솔잎 녹색 |
| Benefit | 금색 보조 표식, 색상만으로 전달하지 않음 |

- 한지 텍스처는 라벨·경로·버튼 대비를 훼손하지 않는다.
- 전국·지역명은 명조 계열, 조작 UI와 수치 정보는 고딕 계열을 사용한다.
- 표준 지도 제공자의 외국 라벨이 전통적 지역명과 충돌하면 전국 뷰에서는 억제한다.
- 문화재 복제품처럼 보이는 과한 붓글씨, 낙관 남용, 가짜 옛 지명은 사용하지 않는다.

## 5. Interaction contract

- 마커, 목록, 하단시트는 하나의 선택 상태를 공유한다.
- 확대·축소, 지역 선택, 검색 결과 선택, 내 위치 이동이 동일한 지도 상태 모델을 사용한다.
- 사용자가 직접 지도를 이동해도 결과를 몰래 교체하지 않는다.
- 전국 뷰 복귀 버튼은 한 번의 탭으로 접근 가능하다.
- 위치를 거부해도 도시 또는 여행 권역을 골라 모든 탐색을 할 수 있다.
- 모션 감소 설정에서는 `flyTo` 대신 즉시 이동한다.
- 최소 터치 영역은 44×44px이며 핵심 텍스트는 11px 미만으로 내려가지 않는다.

## 6. Technology and resilience

- 렌더러는 모바일 안정성을 위해 Leaflet을 유지한다.
- 기본 지도는 실제 래스터 타일을 사용한다.
- 배포 환경에 커스텀 타일 URL이 있으면 이를 우선 사용하고, 없으면 접근 가능한 표준 OSM 타일과 K-Tour 프레젠테이션 레이어로 안전하게 폴백한다.
- 타일 제공자 이름, 저작권 링크와 데이터 출처를 항상 표시한다.
- WebGL 지원 여부가 지도 표시의 전제 조건이 되어서는 안 된다.
- 타일 오류가 발생하면 빈 한지 화면을 성공 상태로 남기지 않고 동일 결과의 목록으로 전환한다.

## 7. Acceptance tests

1. 390×844 모바일 첫 진입에서 대한민국 전체 윤곽과 주요 권역을 3초 안에 이해할 수 있다.
2. 초기 화면에서 주변 국가의 POI와 도로가 시각적 주의를 가져가지 않는다.
3. 전국에서 부산을 선택하고 지역 결과를 본 뒤 한 번의 탭으로 전국으로 돌아올 수 있다.
4. 서울 장소를 선택하면 실제 도로 수준으로 확대되고 하단시트와 핀이 일치한다.
5. 위치를 거부해도 지역 선택, 검색, 목록, 장소 상세 진입이 가능하다.
6. 전통 레이어를 끄면 실제 지도와 POI 동작이 그대로 유지된다.
7. 지도 타일, 마커, 현재 위치, 경로, 목록 전환, 확대·축소가 모바일에서 동작한다.
8. 검색 결과가 없을 때 지도·목록·하단시트가 같은 빈 상태를 보여준다.
9. 색을 구분하지 않아도 마커의 기호와 접근성 이름으로 종류를 알 수 있다.
10. 로컬 및 Vercel 프로덕션 빌드가 통과하고 배포 번들이 구형 WebGL 지도를 포함하지 않는다.

## 8. Out of scope for this visual iteration

- 실시간 대중교통 라우팅과 교통 혼잡도
- 파트너사의 실제 재고·배차·배달 운영 화면
- 전국 행정구역 전체와 등고선의 정밀 GIS 구축
- 개발자가 정의해야 하는 OpenDID/OpenCX/Sui 운영 계약

이번 단계의 목표는 실제 연결 전에도 전국→지역→장소라는 여행 지도 구조와 대동여지도 기반 브랜드 방향을 충분히 판단할 수 있는 고완성도 목업이다.
