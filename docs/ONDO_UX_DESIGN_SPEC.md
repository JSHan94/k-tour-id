# ONDO UX 디자인 명세

상태: `인터랙티브 목업 v1 · 2026-08-18`

이 문서는 App Store의 **「발자취 - 세상에 나를 남기다」**를 시각적 벤치마크로 삼아, 외국인을 위한 한국 식음료 온도 지도 `ONDO`의 화면 언어와 핵심 기능 흐름을 고정한다. 개발 API·데이터 모델·DID 연동 방식은 후속 개발 명세에서 확정한다.

검토용 목업: `/ondo`

## 1. 제품 정의

### 이름

- 소비자 제품명: `ONDO`
- 한글 표기: `온도`
- 설명형 문장: `Where locals eat now`
- K-Tour ID는 소비자 전면 브랜드가 아니라 신원·자격·동의 인프라로 후방에 위치한다.

### 한 문장

> 한국을 잘 아는 로컬의 최신 신호를 바탕으로, 외국인 여행자가 지금 먹으러 갈 동네와 한 끼를 발견하는 지도.

### MVP 범위

- 식당, 시장 음식, 분식, 카페, 디저트
- 야식, 심야 식당
- 전통주, 포차, 바 등 실제 성인 조건이 있는 식음료
- 장소·메뉴·시간에 고정된 소규모 공개 식사 자리

### MVP 제외

- 숙박·교통·쇼핑·뷰티 전반
- 앱 내부 배달·택시 주문
- 결제·스테이블코인·송금
- 공개 사람 검색, 무제한 DM, 범용 커뮤니티 피드
- 방문 배지·브랜드 리워드 중심의 게임화

## 2. 벤치마크 해석

참고 대상: [발자취 App Store](https://apps.apple.com/kr/app/%EB%B0%9C%EC%9E%90%EC%B7%A8-%EC%84%B8%EC%83%81%EC%97%90-%EB%82%98%EB%A5%BC-%EB%82%A8%EA%B8%B0%EB%8B%A4/id6792431474)

### 차용한다

- 대한민국을 작은 점의 집합으로 재해석하는 전국 화면
- 따뜻한 백색과 먹색 중심의 조용한 캔버스
- 색을 콘텐츠 신호에만 제한하는 절제
- 전국 → 지역 → 상세로 들어가는 점진적 탐색
- 카드 그림자보다 여백과 타이포그래피로 만드는 위계
- 둥근 하단 내비게이션과 하단 시트
- 하나의 화면에 하나의 주요 질문만 남기는 구성

### 차용하지 않는다

- 모든 확대 수준을 추상 점 지도로 처리하는 방식
- 실제 장소 탐색에 필요한 검색·필터를 숨기는 극단적 미니멀리즘
- 기록 앱에 적합한 과도한 빈 공간
- 사진에서 추출한 임의 색을 데이터 색으로 사용하는 방식
- 기록·배지·저널을 그대로 복제한 정보 구조
- 아주 작은 점 자체를 터치 타깃으로 사용하는 방식

## 3. 핵심 디자인 문장

> 발자취의 조용한 흑백 한국 지도 위에, 지금 로컬이 주목하는 식음료의 열기만 한 점씩 진해진다.

색은 장식이 아니라 데이터다. CTA, 탭, 혜택, 오류에 온도색을 반복 사용하지 않는다.

## 4. 지도 확대 체계

| 단계 | 지리 단위 | 표현 | 사용자의 질문 |
|---|---|---|---|
| 전국 | 권역 | 점묘 대한민국 + 도시별 ONDO | 지금 한국 어디가 뜨거운가? |
| 도시 | 구·동 또는 격자 집계 | 저채도 지도 + 지역 ONDO | 서울 안에서는 어느 동네인가? |
| 동네 | 장소 클러스터 | 실제 도로 맥락 + 장소 수 | 이 동네에서 무엇을 먹을까? |
| 장소 | 실제 좌표 | 개별 장소 마커 + 하단 시트 | 지금 내가 실제로 갈 수 있는가? |

### 표현 불변식

1. 전국에서 개별 식당 핀을 보여주지 않는다.
2. 도시 진입부터 도로·동네·이동 관계를 읽을 수 있어야 한다.
3. 장소 마커는 실제 좌표를 임의로 이동하지 않는다.
4. 일반 KDE heatmap은 기본 표현으로 쓰지 않는다. 장소 밀도와 ONDO 점수를 혼동시키기 때문이다.
5. 열기 halo는 분위기를 보조할 수 있지만, 판단은 숫자·라벨·카드가 담당한다.
6. 지도 실패 시 같은 정보를 제공하는 온도순 목록이 남는다.

## 5. ONDO 지표의 의미

ONDO는 실제 기온, 혼잡도, 대기시간, 맛의 평점, 안전 점수가 아니다.

> 최근 일정 시간 동안 수집된 로컬 추천·저장·검증 가능한 방문 및 행동 신호를 지역·시간대의 평상시 수준과 비교한 식음료 관심도 지수.

### UI 표기

권장:

```text
ONDO 87 · HOT
24분 전 업데이트
검증된 로컬 신호 14개
이 지역의 평소보다 빠르게 상승 중
```

금지:

```text
87°C
실시간 혼잡도 87
맛 점수 87
```

### 신호 역할 분리

| 데이터 | 시각 표현 |
|---|---|
| ONDO 강도 | 따뜻한 순차색 + 숫자 + 단계명 |
| 최신성 | 시계 아이콘 + 상대 시간 |
| 신뢰도 | 실선/점선 외곽 링 + 문구 |
| 표본 수 | 로컬 신호 건수 |
| 데이터 부족 | 회색 + 점선 + `Limited signals` |
| 선택 | 이중 halo + 하단 시트 |
| 19+ | 달 또는 `19+` 배지 |

데이터 부족은 낮은 ONDO와 다르다. 충분한 신호가 없으면 정밀 점수를 숨긴다.

## 6. 컬러 시스템

순서형 데이터에는 무지개가 아니라 명도 차이를 포함한 순차 팔레트를 사용한다. 참고: [ColorBrewer](https://colorbrewer2.org/), [W3C Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color)

| 범위 | 상태 | Fill | 내부 글자 |
|---:|---|---|---|
| 0–39 | `LOW PULSE` | `#EFE1B7` | `#191816` |
| 40–59 | `WARMING` | `#EBC463` | `#191816` |
| 60–74 | `RISING` | `#E6843B` | `#191816` |
| 75–89 | `HOT` | `#C94832` | `#FFFDF8` |
| 90–100 | `PEAK` | `#7A2048` | `#FFFDF8` |
| 산출 불가 | `LIMITED SIGNALS` | `#CFCAC0` + 점선 | `#191816` |

### 컬러 규칙

- 같은 점수는 도시와 화면이 달라도 같은 색을 쓴다.
- 초록→빨강 신호등색을 쓰지 않는다. 이용 가능·불가능 상태와 충돌한다.
- 파랑→빨강 기온 지도형 팔레트를 쓰지 않는다.
- 연한 단계에는 `#5C5550` 1.5–2px 외곽선을 둔다.
- 색만으로 상태를 전달하지 않고 숫자·단계명·크기 또는 링을 같이 쓴다.
- After 19에서도 단계의 의미와 순서는 유지한다. 야간 배경에 맞는 밝기만 조정한다.
- 저신뢰를 투명도로 표현하지 않는다. 투명도는 낮은 ONDO로 오인된다.

## 7. 정보 구조

### 하단 탭

| 탭 | 역할 |
|---|---|
| 온도 | 전국·도시·동네·장소 탐색 |
| My Korea | 저장, 최근 본 곳, 예정된 식사, 방문 기록 |
| 연결 | 장소와 시간에서 생성된 Pulse Table과 그룹 대화 |
| ID | Person·19+ 자격, 동의와 갱신 상태 |

### 지도 홈에 남긴다

- ONDO 이름과 현재 도시
- 장소·음식·분위기 검색
- `지금`, `오늘 저녁`, `늦게까지`
- After 19 진입점
- 내 위치, 지도/목록 전환, 필터
- 짧은 온도 범례와 기준 시간
- 선택 지역 또는 장소 Peek Card

### 지도 홈에서 숨긴다

- DID·지갑 세부 상태
- 결제·KYC 정보
- 배지와 방문 통계
- 커뮤니티 피드
- Pulse 계산식 전체
- 모든 음식 카테고리 칩
- 지도 설정 버튼 묶음

## 8. 주요 사용자 흐름

### 8.1 첫 진입

```text
ONDO 설명
→ “날씨가 아니라 최근 로컬 식음료 신호” 안내
→ 지도 홈
→ 내 주변을 눌렀을 때만 위치 권한 요청
```

온보딩은 최대 두 장 또는 지도 위 coach card로 끝낸다. 인증·여권·DID를 탐색 전에 요구하지 않는다.

### 8.2 기본 탐색

```text
전국 ONDO
→ 도시 선택
→ 동네 선택
→ 장소 선택
→ 뜨는 이유와 가기 전 확인
→ 저장 또는 길찾기
```

장소 카드의 정보 순서:

1. 한글 원문 장소명 + 영문명
2. 대표 음식과 영업 상태
3. ONDO, 최신성, 신호 수
4. 가격대와 거리
5. 해외카드·한국 번호·영문 메뉴·예약 조건
6. 저장·길찾기·Pulse Table

### 8.3 After 19

```text
19+ 식음료 필터 또는 제한 장소 선택
→ “생년월일 대신 19세 이상 여부만 확인” 설명
→ 지금 확인 / 나중에
→ 성공: 원래 지도 위치와 선택 장소로 복귀
→ 취소·실패: 기본 ONDO는 계속 사용
```

심야 식당·24시간 카페는 기본 지도에 남긴다. 실제 주류·법적 성인 조건이 있는 콘텐츠만 제한한다.

### 8.4 연결

```text
장소 상세
→ 특정 날짜·시간의 Pulse Table 확인
→ 공개 장소·메뉴·언어·예상 비용 확인
→ 참여
→ 필요한 경우에만 Person/19+ 확인
→ 참가 확정 후 그룹 대화
```

성별 비율, 소개팅 목적, 실시간 위치 공유, 무제한 1:1 DM은 없다.

## 9. 실패·경계 상태

### 신호 부족

```text
Busan · Growing
새로운 로컬 신호를 모으는 중
편집 추천 8곳 보기
```

### 오래된 데이터

- 현재 시간창을 벗어난 ONDO는 Live 화면에서 제거한다.
- 필요하면 `마지막 로컬 신호 9시간 전`로만 보여준다.
- 오래된 빨간 ONDO를 단순히 흐리게 남기지 않는다.

### 위치 권한 거부

- 전국 지도와 도시 수동 선택을 그대로 제공한다.
- 권한 거부를 전체 화면 오류로 만들지 않는다.

### 지도 실패

- 온도순 목록을 즉시 제공한다.
- 지도 타일 실패와 ONDO API 실패를 분리한다.

### 필터 결과 없음

```text
이 조건에 맞는 곳이 아직 없어요
[필터 초기화] [반경 넓히기]
```

## 10. 접근성·모션

- 보이는 점이 작아도 터치 영역은 최소 44×44px다.
- 일반 텍스트는 4.5:1, 조작 경계와 상태는 3:1 이상 대비를 목표로 한다.
- 색을 제거해도 숫자·단계명·목록으로 같은 결정을 내릴 수 있어야 한다.
- 각 마커는 `성수, ONDO 87, Hot, 24분 전 업데이트`처럼 완전한 접근성 이름을 가진다.
- 지도와 같은 내용을 가진 키보드·스크린리더용 목록이 존재한다.
- 진동하는 pulse 애니메이션은 금지한다.
- 새 신호는 한 번만 180–240ms 확대하고 정지한다.
- `prefers-reduced-motion`에서는 즉시 상태를 전환한다.

## 11. 목업에서 확인할 기능

- 전국 점묘 지도와 도시 선택
- 도시 지도, 동네 ONDO와 장소 선택
- 지도/목록 전환
- 시간·식음료 필터
- ONDO 정의와 범례
- 장소 상세와 `가기 전 확인`
- 저장과 My Korea 반영
- 외부 길찾기 선택
- After 19 JIT 확인·취소·성공
- 장소 기반 Pulse Table 참여
- ID 탭의 Person·19+ 상태
- 신호 부족 지역과 지도 대체 목록
- 한국어/영어 전환

## 12. 목업 판정 기준

1. 5초 노출 후 사용자가 가장 뜨거운 도시를 찾을 수 있다.
2. ONDO를 실제 기온·혼잡도·안전도·맛 평점으로 오해하지 않는다.
3. 전국 → 도시 → 동네 → 장소를 도움 없이 이동할 수 있다.
4. 장소 상세에서 10초 안에 영업·가격·이용 조건·길찾기를 판단한다.
5. 색을 구분하지 못해도 숫자와 단계명으로 같은 결정을 내린다.
6. 인증을 취소해도 기본 지도로 복귀하며 막힌 흐름이 없다.
7. 저장한 장소가 My Korea에 즉시 반영된다.
8. Table 참여 후 연결 탭에 대화 맥락이 생긴다.
9. 390×844, 430×932, 데스크톱 중앙 프레임에서 잘리지 않는다.
10. 지도 실패 상태에서도 목록 탐색이 가능하다.

## 13. 후속 개발 명세에서 정할 것

- ONDO 산식, 정규화 범위, 신호 감쇠 시간
- 데이터 산출 최소 기여자·최소 표본 기준
- 행정동·H3 등 실제 집계 단위
- 로컬 신호 수집·조작 방지·신뢰도 모델
- 지도 타일 공급자와 SLA
- 외부 지도별 길찾기 handoff 규칙
- After 19 실제 발급자·검증자·법적 나이 기준
- Pulse Table 신고·차단·운영 SLA
- Leaflet 유지와 MapLibre 전환 기준
