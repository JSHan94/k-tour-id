## 사용자 지적 → 수정

1. 온보딩 배경까지 56dvh가 적용되는 선택자 충돌을 수정. 전체 투명 overlay와 full-viewport scrim, 모바일 하단 시트 분리. 작은 가로 화면도 실제 시트 폭을 기준으로 단일 열 선택지.
2. 도시 기본 시점 28°, 사용자 평면 선택·이력 카메라·전국 0° 복원. 기존 OpenFreeMap building footprint에 낮은 fill-extrusion을 적용하며 가까운 배율에서만 표현. 표시 높이 18m cap은 시각적 제한이며 건물 실측 높이를 의미하지 않는다. 샘플 지도 첫 카메라는 신호가 있는 장소를 중심으로 잡지만 전체 검색 결과는 바꾸지 않는다.
3. 샘플 열장과 작은 마커, 장소 미리보기의 활동 표현이 동일한 프레임을 공유. 고정된 최고점 마커가 샘플 위를 덮지 않음. 새 마커도 실제 좌표에 44px hit target·가장 가까운 점 선택. 기존 장소 점수·권한·영수증·데이터 저장과 분리.
4. After 19 × light/dark를 실제 2축 팔레트로 분리. 지도 제어·타임라인·목록·검색·탭은 전역 테마의 surface를 사용. 야간 탐색은 필터·라벤더/로즈 강조이며 별도 다크모드가 아니다. 비활성 전체 범주 바를 작은 컨텍스트 표시로 교체.

## 실행 메모

- 개발 서버의 webpack eval은 배포용 CSP에 차단되므로 브라우저 판정은 배포용 production build에서 수행한다. 이를 위해 CSP를 완화하지 않는다.
- 전체 계약의 packaging 테스트는 `.ondo-b-standalone`를 재생성한다. 최종 검수는 서버 종료 → 전체 계약 → production build → 브라우저 → 배포 순서로 수행한다.
- 첫 후보 화면 교차 검수에서 가로 온보딩 선택지 줄바꿈과 라이트 After19 목록 아이콘의 잔여 흰색을 추가로 수정했다.
